# Product Requirements Document - JournalAI

## Overview
JournalAI is a voice-first journaling application that helps users maintain accountability towards their goals through AI-powered daily reviews and progress tracking.

## Problem Statement
People struggle with goal accountability due to:
- Difficulty following up on goals set during different mental states
- External accountability systems that feel imposed rather than self-driven
- Existing tools having high friction and poor reflection capabilities

## Solution
A frictionless voice journaling app that:
- Captures thoughts throughout the day via voice notes
- Provides AI-generated daily and weekly reviews
- Tracks progress against personal goals with a scoring system
- Gamifies personal growth through stats and leveling

## Core Features

### 1. Voice Journaling
- One-tap voice recording from home screen
- Natural language processing
- Automatic transcription and categorization
- Multiple entries per day

### 2. AI Reviews
- **Daily Reviews**: Generated at 9 PM daily
  - Progress score (0-100) against stated goals
  - Key achievements and areas for improvement
  - Actionable insights
  
- **Weekly Reviews**: Generated Sunday at 9 PM
  - Aggregated daily performance
  - Trend analysis
  - Goal alignment assessment

### 3. Goal Setting & Tracking
- Initial goal diagnostic during onboarding
- Current goals, yearly goals, 10-year vision
- Dynamic goal categories based on user priorities
- Progress visualization

### 4. Gamification System
- Experience points (XP) based on daily performance
- Dynamic skill categories (health, work, relationships, etc.)
- Level progression
- Achievement milestones

### 5. Task Recommendations
- AI-generated daily task suggestions
- Aligned with user goals
- Based on previous performance patterns

## User Journey

### Onboarding
1. User downloads app
2. Sets up account
3. Completes goal diagnostic
4. Configures notification preferences

### Daily Use
1. Opens app throughout the day
2. Taps microphone button
3. Records voice note
4. Reviews AI feedback at 9 PM
5. Tracks progress and stats

## Success Metrics
- Daily active users
- Average voice notes per user per day
- Review engagement rate
- Goal completion rate
- User retention (30-day, 90-day)

## MVP Scope
1. Voice recording and transcription
2. Daily AI reviews
3. Basic goal tracking
4. Simple progress scoring

## Future Enhancements
- Weekly/monthly/yearly reviews
- Advanced gamification
- Social accountability features
- Integration with calendar/task apps
